# Hi, I'm Sam

AI Solutions Manager at DoorDash. I build production AI for operations teams, lead the people who run it, and teach organizations to adopt it. I came up through operations and emergency response (EMT and behavioral-health crisis response with the Phoenix Fire Department), then taught myself to ship production software.

## What I work on

- An AI support workspace I built from prototype into a production platform: an LLM copilot grounded by server-side retrieval over a support playbook, with relays to other teams' agents.
- AI adoption: training that has reached 800+ people, and an org-wide learning series on building with AI.
- 200+ pull requests merged in 2026.

## Claude Code

Claude Code is my daily engineering environment: custom skills, hooks, MCP servers, persistent memory, and multi-agent builds with review gates. Anthropic's Claude Code team recently recognized me as one of Claude Code's top users.

- **[Agent OS](https://github.com/desertcache/agent-os)**: open-source hooks, skills, memory and session lifecycle management for Claude Code.
- **[Starship Explorer](https://desertcache.github.io/starship/)**: a walkable Three.js starship, built by a coordinated team of Claude Code agents with a reviewer gate.
